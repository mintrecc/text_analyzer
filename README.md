# TEXT ANALYZER
This project is a powerful text analysis tool that provides detailed statistics, including sentence-by-sentence analysis. It can count words, unique words, capitalized words, numbers, and even track mathematical sign alternations.

### How to use:

**Option 1: Using a file**

You can put your text in the`test.txt` file located `length/data/test.txt`. And then just run the script `python main.py -f`. You can write your own path `python main.py -f length/data/test.txt`

**Option 2: Using the terminal**

You can also pass your text directly via the command line as an argument. 
 Example: `python main.py "The quick brown 5 fox 8 jumps -3 Over -1 the 0 lazy 4 dog."`
